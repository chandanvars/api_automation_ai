# api_automation_ai

## Project Overview

This project is aimed at automating API testing using a robust framework designed for ease of use and scalability. The repository contains all necessary components to start testing APIs efficiently and effectively.

## Getting Started

### Prerequisites

- **Git**: Ensure that Git is installed on your machine.
- **Java**: The framework is built using Java, so make sure you have Java Development Kit (JDK) installed.
- **Maven**: This project uses Maven for dependency management. Install Maven if it's not already installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/chandanvars/api_automation_ai.git
   ```

2. Navigate into the project directory:

   ```bash
   cd api_automation_ai
   ```

3. Checkout the feature branch for API automation framework:

   ```bash
   git checkout feature/api_automation_framework
   ```

4. Build the project using Maven:

   ```bash
   mvn clean install
   ```

## Usage

### Running Tests

To execute the test cases, use the following Maven command:

```bash
mvn test
```

### Adding New Test Cases

1. Navigate to the `src/test/java` directory.
2. Create a new Java class with the necessary test annotations and methods.
3. Implement your test logic using best practices.
